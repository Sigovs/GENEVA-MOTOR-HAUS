Design system · developer handoff

Build Geneva from these parts.

Tokens, eleven components, the entrance motion, the page patterns and the rules behind them. Everything here is plain HTML and CSS; the values come from the live site's stylesheets, and every size was measured from its rendered components.

  • tokens.cssevery token as a custom property
  • tokens.jsonthe same tokens as data
  • geneva-ds.cssthe components and motion roles
  • Live previewthe site these were taken from

Generated 14 Sep 2026 from assets/css/tokens.css and geneva-final-v2.css.

Start

Two stylesheets, two faces.

Load the fonts, then tokens.css, then geneva-ds.css. Put g-page on the body for the ground, the ink and box sizing. Components are self-contained classes; nothing depends on page structure.

  • Use tokens, never raw colours or sizes.
  • Nothing functional below 14px (--t-micro).
  • Every text pair meets WCAG AA; the table under Tokens shows each ratio.
  • Every animation has a reduced-motion path: the page arrives complete.
  • Browsers: current Chrome, Safari, Firefox, Edge. Uses clamp(), color-mix(), :user-invalid, the translate property.

Motion

Once, stepped, then still.

A section opts in with data-reveal and marks its parts with a role. One observer adds is-revealed once, when the section's top passes 78% of the window. The CSS writes only the hidden state, so nothing stays transformed afterwards. Under reduced motion the observer never arms and nothing is ever hidden.

The observer (the only script)

(function () {
  var targets = [].slice.call(document.querySelectorAll('[data-reveal]'));
  if (!targets.length || !('IntersectionObserver' in window)) return;
  if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) return;
  document.documentElement.classList.add('reveal-armed');   // nothing is hidden before this line runs
  var io = new IntersectionObserver(function (entries) {
    var k = 0;
    entries.forEach(function (entry) {
      if (!entry.isIntersecting) return;
      io.unobserve(entry.target);                               // once per visit
      if (entry.target.classList.contains('rv-self')) entry.target.style.setProperty('--rv-batch', k++);
      entry.target.classList.add('is-revealed');
    });
  }, { rootMargin: '0px 0px -22% 0px' });                      // when the top passes 78% of the window
  targets.forEach(function (t) { io.observe(t); });
})();
  • Scroll-triggered, never scroll-linked; one entrance per visit.
  • Transform and opacity only; nothing animates layout.
  • Hover: a button's arrow moves 2px, a card's photograph scales to 1.04; nothing else moves under the pointer.
  • Rejected on this project: scroll-drawn rings and lines.

Rules

What holds on every page.

Content

  • Words and figures are the client's, trimmed, never extended. Each page on the site has a ledger of every claim and its source (docs/content-ledger-*.json).
  • Dated figures carry their date on screen: prices and mileages read “as listed 14 Sep 2026”.
  • Photographs are Geneva's own. No stock; no photograph under a car it is not.
  • Left out on purpose: “12+ years”, “5000+ sold”, “98%”, “within 24 hours”, “best price”, “no hidden fees” — unconfirmed by the client.
  • Forms keep the AAN field names and required sets.

Accessibility

  • WCAG AA contrast for every text pair (see Tokens).
  • 14px minimum for anything functional.
  • Visible focus: 2px --ink ring (2–3px offset); inside the control on list rows.
  • Every field has a label; errors are a colour plus the browser's message, never colour alone.
  • Reduced motion: nothing hidden, nothing moving.
  • The same content on a phone; the summary panel is the one thing hidden, because the form is complete without it.

Never

  • Red text on the dark ground; underlined navigation; gradient buttons; decorative shadows.
  • A numbered side rail that reads as a document outline.
  • A placeholder instead of a label, or a mailto link dressed as a form.
